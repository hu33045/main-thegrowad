# 더성장애드 홈페이지 5단계 구현본

`index.html` 파일을 브라우저로 열어 확인할 수 있습니다. GitHub Pages에는 폴더 안의 모든 파일을 함께 업로드합니다.

- 디자인: 네이비·민트·화이트 원페이지 반응형
- 5개 섹션과 메인 3장 자동 슬라이드(3단계 이미지 재사용)
- 제작 사례: 아직 실제 자료가 없어 준비 중으로 표기
- 카카오톡 채널 주소: 확인 필요로 외부 이동 비활성화
- 서비스 세부 범위: 확인 필요
- 3단계 생성 이미지에서 변환한 WebP 자산입니다. 일부 이미지에 생성된 문자가 포함되어 있을 수 있으므로 공개 전 검토하세요.

- 네이비/민트/화이트 유지, 각 슬라이드의 은은한 배경 변화
